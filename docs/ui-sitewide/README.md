## 共通方針

- 本文16px、補助14px、見出し22px、ページタイトル32pxを基本とする4段階。
- 生成りと緑の既存配色を維持し、背景・文字・操作・境界・フォーカスの役割を共通変数で管理。
- 暗い背景上の主要ボタン文字に固定の明るい前景色を使い、背景用変数の流用を解消。
- 角丸は16px・8pxを基本に整理。影は本の検索候補など重なりを伝える場所だけ。
- ホバー時のカードの浮き上がりや装飾的な動きを削除。
- 本文へのスキップリンク、現在位置、進捗バーのアクセシブルな属性を追加。
- レビュー・感想など既存の記録本文と書誌データは変更しない。見せ方をテンプレートで調整。
- 操作に必要な説明・公開時の注意・エラー理由は残す。

## フォームの動作変更

- 必須入力のエラーをフォーム内に表示し、対象入力へフォーカスを移す。
- 入力や選択した本を変更したら以前の生成結果を無効化し、古い文章のコピーを防ぐ。
- 生成後は出力へフォーカスを移し、キーボードで確認できるようにする。
- 本の検索候補は書名を折り返し、著者・ISBN・状態を保持。
- 公開データへの自動送信は行わず、従来どおり文章を生成してChatGPTへ渡す。
