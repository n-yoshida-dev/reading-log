ADD / UPDATE

何を書けばいいか、
思い出さなくていい。

必要な質問に答えるだけで、reading-logへ反映するためのChatGPT用テキストを作ります。

使い方

フォーム入力 → 「ChatGPT用テキストを生成」→ コピー → ChatGPTプロジェクト「読書管理」に貼り付けてください。入力途中の内容はこの端末に自動保存されます。

このリポジトリは公開です。勤務先・家族・健康・家計など、公開したくない個人情報は入力しないでください。

NEW BOOK

新しい本を登録

書誌情報は全部埋めなくてOK。Amazon等の情報をそのまま貼っても使えます。

READING NOTE

読書中のメモ

全部埋める必要はありません。残したい項目だけで十分です。

FINISH / REVIEW

読了・感想

感想を思い出すための質問です。短くても、辛口でも、そのままでOK。

OUTPUT

ChatGPTに渡す文章

生成した文章をそのまま「読書管理」プロジェクトへ貼り付ければ、既存ルールに沿ってGitHubへ反映できます。
